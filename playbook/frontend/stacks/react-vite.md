# React Vite 스택

## 규칙
- 화면/라우트 모듈의 책임을 작게 유지한다.
- 뷰 레이어와 데이터 접근 레이어 경계를 명확히 둔다.

## Do
- Vite 설정은 최소화하고 기능 코드는 프론트 패턴에 맞춰 유지한다.

## Don't
- UI 모듈에 서버 도메인 로직을 직접 섞지 않는다.

## 예시
```tsx
function UsersPage() {
  const { data } = useUsersQuery();
  return <UsersTable rows={data ?? []} />;
}
```

## 경계
- View 레이어는 렌더링/상호작용을 담당한다.
- Data 훅 레이어는 패칭/캐시 정책을 담당한다.

## 테스트 범위
- 컴포넌트 렌더링과 사용자 상호작용을 검증한다.
- 변경 완료 전 프론트 테스트 또는 최소 타입체크/린트를 반드시 수행한다.
